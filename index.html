Canva e IA

Canva

Introducción

Canva es una plataforma muy conocida para diseñar presentaciones, pósteres o infografías, pero también incorpora una función muy útil: la Programación mediante IA, capaz de generar aplicaciones y applets interactivos en HTML a partir de un prompt.

¿Para qué puede servir Canva en Matemáticas?

  • Crear presentaciones o infografías para explicar conceptos (fracciones, ecuaciones, proporcionalidad…).
  • Diseñar juegos gamificados como:
    1. Trivials o cuestionarios autocorregibles,
    2. Tableros de retos matemáticos
    3. Tarjetas de memoria (flashcards)
    4. Ruletas aleatorias con problemas
    5. Juegos de “verdadero o falso”
    6. Breakouts o escape rooms educativos
  • Usar la IA de programación para generar:
    • Pequeños applets HTML que representen funciones, figuras geométricas o simulaciones
    • Generadores aleatorios de ejercicios
    • Minijuegos interactivos basados en Matemáticas

Ejemplo práctico

Con Canva puedes pedir a la IA:

“Crea un applet en HTML que represente una recta numérica y permita mover un punto para visualizar su coordenada.”

Canva generará el código y podrás visualizarlo o exportarlo.
