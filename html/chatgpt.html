ChatGPT

Introducción

ChatGPT funciona como un acompañante de estudio que puede adaptarse al nivel de cada alumno o alumna. Su papel NO es hacer los ejercicios, sino ayudarte a entenderlos, corregir errores y aprender paso a paso.

¿Cómo puede ayudarte ChatGPT en Matemáticas?

  • Explicar ejercicios a partir de una imagen: puedes hacerle una foto a un problema y pedirle que lo explique paso a paso.
  • Corregir ejercicios y analizar errores: ChatGPT puede mostrar dónde te has equivocado y por qué.
  • Explicar partes del tema que no comprendes: puedes pedirle que te explique algo “como si fuera un profesor particular”.
  • Resolver dudas específicas: “No entiendo cómo despejar la incógnita en esta ecuación”, “Explícame cómo funciona la proporcionalidad compuesta…”
  • Crear recursos de estudio: te ayuda a escribir prompts que luego puedes usar en Canva para generar un applet o un juego interactivo.
  • Generar Applets sin diseño: generar directamente el código HTML de un applet para visualizar de forma simple, sin diseño.

Ejemplo práctico

Ejemplo de un prompt para ChatGPT:

“Genera un applet HTML sencillo que permita introducir dos números y muestre su MCM y MCD.”

ChatGPT generará el código y creando el archivo de la forma correcta, se pobra visualizar mediante Chrome o cualquier otro navegador.
