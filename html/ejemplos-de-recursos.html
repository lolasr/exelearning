Librojuego

Diseña una herramienta educativa interactiva con estética de librojuego para aprender a resolver ecuaciones de primer grado. La interfaz debe ser visualmente atractiva, colorida y orientada a estudiantes jóvenes. Características que debe incluir: Pantalla principal con diseño tipo librojuego, con portada ilustrada tipo “aventura matemática”. Capítulos o niveles, presentados como páginas de un libro o escenas de una historia. En cada nivel, el alumno debe resolver ecuaciones de primer grado, del estilo: a·x = b a·x + c = d Cada ejercicio debe mostrar: La ecuación Un campo para que el estudiante introduzca el valor de x Un botón de “Verificar” Un mensaje dinámico de correcto / incorrecto Debe incluir también un botón de “Siguiente desafío” que genere una nueva ecuación. Debe mantener el estilo narrativo del librojuego: Personajes que animan al estudiante Pequeñas ilustraciones mágicas o fantásticas Efectos visuales suaves (luces, pergaminos, páginas, etc.) El diseño debe ser limpio, legible, con botones grandes y colores amigables. Todo debe tener apariencia de aplicación interactiva, aunque no necesita programarse completamente: solo generar la interfaz visual con los elementos preparados para que luego pueda añadirse interactividad. Objetivo final: Crear una interfaz completa que represente un librojuego educativo donde el aprendizaje de ecuaciones sea divertido, visual y gamificado. Además, en cada capitulo pon algo de la aventura, algo que se consigue al haber resuelto bien todas las ecuaciones
