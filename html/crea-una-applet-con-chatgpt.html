Crea una applet con ChatGPT

EJEMPLO - Applet de ecuaciones en HTML

1. Pasamos el prompt a ChatGPT: 

“Ahora quiero que me fabriques un applet en HTML para estudiar ecuaciones de 1º grado. El applet debe incluir varios ejercicios donde yo tenga que escribir la solución en un cuadro de texto y el programa me diga si la respuesta es correcta. Quiero que sea código HTML, CSS y JavaScript sencillo, para copiarlo en un archivo .txt y que sea funcional.”


2. Guardamos en archivo .txt como UTF-8 con extensión .html

3. Abrimos el archivo con el navegador

4. ¡A jugar!
